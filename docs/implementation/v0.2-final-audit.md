## Expanded replay and refinement evidence

The repeated-build gate builds each of these systems twice under independent
output roots and compares every PYC, C++, Verilog, primitive, profile, and
manifest file byte-for-byte:

- barrier;
- credit;
- explicit Python firing;
- loop `break`/`continue`;
- typed memory;
- compile-time recursion;
- runtime Queue collection select.

The DavinciOO projection also checks:

- dependency-window peak occupancy `8`;
- per-resource executing peaks `[1, 1, 0, 1]`;
- reorder-window peak occupancy `8`;
- completion and retirement order;
- architectural values;
- the 453-cycle oracle.

PYC C++ and Verilator cycle-equivalence gates cover the stateful and atomic
building blocks. Verification-role `ac.expect` is intentionally rejected from
PYC design hierarchy with testbench-boundary guidance; this is a role contract,
not a missing design lowering.

## Sanitizer environment note

The macOS ASan run used:

```text
allow_user_poisoning=0
detect_container_overflow=0
detect_leaks=0
strict_string_checks=1
halt_on_error=1
```

Homebrew's unsanitized LLVM libraries use bump-allocator poison annotations
that conflict with a sanitized executable. The first run reproduced that
external `llvm::StringSaver` use-after-poison signature. The compatibility
settings above match the repository's earlier audits and leave project address
instrumentation and halt-on-error enabled. Linux CI retains independent poison,
container, and leak gates. UBSan ran with stack traces and halt-on-error without
compatibility settings.

tree contains the public QueueGraph headers and gfsim templates, including the
