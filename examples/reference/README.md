# Reference Models

This directory contains non-installed models used as concrete baselines for
Agentic Circuit lowering and C++ code generation. A reference model is not a
second runtime implementation and does not extend the public component or CLI
contracts.

Current references:

- [`davincioo-gfsim`](davincioo-gfsim/README.md) — provenance-locked snapshot
  of the DavinciOO out-of-order NPU model.
